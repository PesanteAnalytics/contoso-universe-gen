- YAML category plugin system documentation
- Language impact reference (what changes per locale, what stays in English)
- CLI flags reference and quick recipes
- DuckDB analytical views documentation (3 auto-created views)
- SQL Server integration notes
- Professional folder structure with `examples/` and `config/` subdirectories
