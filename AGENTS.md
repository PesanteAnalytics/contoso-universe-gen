# 🤖 Agent Policy — Contoso Universe Generator

This is an **active development repository**.
AI agents working here can read, modify, execute, and create files freely.

## ✅ Allowed

- Read, edit, and create any file in this repository
- Execute scripts and run CLI commands (`cug`, `python`, `uv`)
- Commit changes and manage Git branches
- Install dependencies within the virtual environment (`.venv/`)

## ⚠️ Important Notes

- **`_pal-internal/`** → private folder for the PAL team, not published. Contains
  internal plans, operational skill configs, and analysis scripts.
  You can read and work with these files — just know they are never committed.

- **`CUG-CONFIG.md`** → per-user configuration card (gitignored). Generated by
  `cug init` or the agent skill. Always at the project root.

- **`.agent/`** → active agent skill directory (gitignored). Contains the live
  skill configuration with local paths.

- **`output/`** → generated datasets (gitignored). Never commit data files.

## 🛠️ Key Commands

```bash
# Generate data
python -m cug generate -c cug/configs/default.toml

# Run tests
python -m pytest tests/

# Install dependencies
uv sync
```

_See `docs/` for full documentation and `_pal-internal/agents/AGENTS.md` for PAL-specific policies._
